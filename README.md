# ⛅ Weather App

A simple and responsive real-time weather application built with HTML, CSS, and JavaScript.

## Features

- Search weather by city name
- Real-time temperature
- Humidity information
- Wind speed
- Feels-like temperature
- Dynamic weather conditions and icons
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open `index.html` with Live Server.
4. Enter a city name and click **Search**.

## API

Weather data is provided by the Open-Meteo API.
